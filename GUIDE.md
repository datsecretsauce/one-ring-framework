# Practical Guide

1. Start by classifying the task.
2. State objective, success criteria, constraints and approved scope.
3. Use Floor First: propose the smallest viable change.
4. Apply the principles required by the tier.
5. Trigger the Stop Rule before scope expansion.
6. Run verification appropriate to the claim.
7. For CHANGE and COMMITMENT, hand the attribution-neutral audit package to an Auditor.
8. Require a Coverage Statement even when no findings are reported.
9. Resolve falsifiable disputes with tests. Log non-testable material disputes for the human.
10. Any remediation re-enters at CLASSIFY.
11. End with the evidence footer and required sign-off.
