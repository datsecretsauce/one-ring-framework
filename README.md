# The One Ring Framework v3.1
## An Open Builder / Auditor Protocol for AI-Assisted Engineering

**Author: Ricky Sng**

Rule 0: **Truth and verification outrank confidence, elegance, speed and agreement.**

This toolkit provides a tiered governance protocol for AI-assisted software engineering.

### Engineering tiers
- **PATCH** - Rule 0 + classification + Stop Rule + proportionate verification + footer.
- **CHANGE** - Principles 1-8 + verification + independent Auditor + Coverage Statement + footer.
- **COMMITMENT** - All 11 + strongest appropriate runtime verification + independent Auditor + Coverage Statement + human sign-off.

### Core controls
The Builder may escalate a tier at any time and may never downgrade it. Only the human may downgrade, with recorded rationale. Audit-driven remediation re-enters at CLASSIFY. Model agreement is not verification. Runtime-required claims require runtime evidence or remain unresolved.

See `SPEC.md` for normative requirements and `GUIDE.md` for practical use.
